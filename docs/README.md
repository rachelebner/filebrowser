# Docs

- `prod` is the deployed branch. It is the default branch of this repo.
- It carries File Browser v2.63.14 plus the Markdown URL and RTL frontend backport.
- Every push to `prod` deploys to the Mac Mini. See [deploy-macmini.md](deploy-macmini.md).
- Backport details are in [markdown-rtl-backport.md](markdown-rtl-backport.md).
- `master` is a separate line. Do not merge it into `prod`.
